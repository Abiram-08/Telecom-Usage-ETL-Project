# Project Summary

## Project Title

Telecom Usage ETL Data Integration

## Objective

Develop an end-to-end ETL workflow to integrate customer, telecom usage, and subscription plan data from multiple sources into a centralized reporting table.

## Source Systems

- MySQL (Customer)
- Oracle Database (PLAN)
- CSV Flat File (Telecom Usage)

## Target

- MySQL (telecom_usage_report)

## Transformations

- Source Qualifier
- Joiner
- Expression

## Technologies

- Informatica PowerCenter 10.4.1
- MySQL
- Oracle Database
- SQL
- CSV
