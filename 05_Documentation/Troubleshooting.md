# Troubleshooting

## Issue 1

**Problem**
ODBC Data Source Name not found.

**Solution**
Configured the correct ODBC DSN and updated the session connection.

---

## Issue 2

**Problem**
Oracle connection failed.

**Solution**
Updated the session to use the correct Oracle relational connection.

---

## Issue 3

**Problem**
Joiner datatype mismatch.

**Solution**
Converted datatypes using an Expression transformation before the Joiner.

---

## Issue 4

**Problem**
Workflow execution failed.

**Solution**
Verified session configuration and corrected the database connections.
