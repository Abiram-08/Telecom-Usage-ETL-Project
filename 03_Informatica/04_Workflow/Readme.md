# Workflow

## Overview

This folder contains the Informatica PowerCenter workflow used to execute the Telecom Usage ETL project.

## Workflow Name

- **wf_telecom_usage_report**

## Session Name

- **s_m_telecom_usage_report**

## Workflow Process

1. Extract data from MySQL, Oracle, and CSV.
2. Execute the ETL mapping.
3. Apply required transformations.
4. Load the data into the MySQL target table.
